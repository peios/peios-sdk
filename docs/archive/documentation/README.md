# Documentation Archive

This directory preserves the documentation that preceded consolidation into
the Peios SDK. Archived files describe their original checkout and can
contain obsolete commands, project boundaries, and implementation plans.
Use the maintained guides under `docs/learn/` and the contributor documents
in `docs/` for the consolidated repository.

`sources.json` records every preserved source, archive path, SHA-256 digest,
and maintained destination where one exists. Repository design notes and
implementation maps remain historical evidence rather than release claims.
The Learn migration keeps Rust bindings, the Go SDK, and cross-component
event design in their existing documentation ownership.
